Configurar o Jellyfin

Cria a conta administrativa Jellyfin, ou usa a conta existente para retomar a configuração. As palavras-passe NOVA e Jellyfin são independentes. A NOVA não guarda a palavra-passe Jellyfin.

Escolhe uma biblioteca para as duas origens, ou separa filmes e séries em bibliotecas diferentes. A indexação pode demorar; atualiza a verificação para consultar a contagem. A configuração inicial usa metadados locais e desativa o acesso remoto numa instalação Jellyfin nova.

Dispositivos

Introduz o código apresentado pelo cliente de teste. Confirma que o nome e o código correspondem ao teu dispositivo antes de aprovar. Esta autorização permite apenas identificar o dispositivo; a biblioteca e a reprodução ainda não estão disponíveis.
